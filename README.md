# Realme-GT5Pro-
酷安@对公户的相机补全模块分支
模块二改自酷安@对公户，现在作为一个分支在独立维护

更新频率:
当上游模块更新时（预25年5月恢复更新），24小时内会合并上游更新
当上游模块暂时停更（现期）:看心情（因为现版本的模块已经很完善了，除非相机底层有变动需要单独适配）

模块运行的:
1.XPAN主摄与长焦
2.主界面点击当前焦段再次切换
3.AI长焦（仅装饰）在20x焦段触发
4.大师模式（仅UI）
5.街拍模式
6.人像模式柔光选项
7.光影有声滤镜修复
8.视频录制最高8k30fps
9.视频录制全焦段最高4k60fps杜比视界

模块不工作的:
1.RAW拍摄所有的
2.大师模式效果
3.功耗问题
4.需要配套相机APK（模块已内置）
